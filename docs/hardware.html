🔈 Speaker

Jangan sambung speaker ke GPIO langsung.

ESP32 BCLK/LRC/DIN → MAX98357
MAX98357 VIN ← setelah saklar (baterai)
OUT+/OUT− → speaker 4–8Ω

⚡ Power

LiPo → TP4056 (+DW01) → Saklar → VIN ESP32 + VIN MAX98357
ESP32 3V3 → LCD + SD + TTP223
GND bersama

🧩 Urutan rakit

  1. Case + LCD
  2. GND → 3V3 → SPI → touch → I2S
  3. Speaker ke OUT amp
  4. TP4056 berproteksi → saklar → VIN
  5. Flash firmware ≥ 0.2.8
