🔈 Speaker — jangan ke GPIO!

⚠️ Speaker HP / speaker kecil tidak boleh disambung langsung ke pin GPIO ESP32.

  • GPIO hanya sinyal digital (3.3V, arus kecil) — tidak cukup menggerakkan speaker.
  • Sambungan langsung bisa merusak pin ESP32.
ESP32  BCLK → MAX98357 BCLK
       LRC  → MAX98357 LRC
       DIN  → MAX98357 DIN
MAX98357 VIN ← setelah saklar (baterai)
MAX98357 OUT+ / OUT− → speaker 4–8Ω

✅ Selalu: ESP32 → amp I2S → speaker.

⚡ Power path

LiPo → TP4056 → Saklar → VIN ESP32 + VIN MAX98357
ESP32 3V3 → LCD + SD + TTP223
GND bersama

🛡️ Pin boot-safe

TFT MOSI=6  SCLK=4  CS=7  DC=10  RST=0
SD MISO=3  CS=5  (SCK/MOSI berbagi 4/6)
Touch=1
I2S BCLK=21  LRC=20  DIN=8
GPIO2 & GPIO9 kosong (strap/BOOT)

🔊 SFX reaksi (firmware 0.2.4+)

Saat ketuk, firmware mencari file di SD lalu jingle flash:

/sfx//.wav   contoh /sfx/wajah/yelling.wav
/sfx/.wav
/sfx/.wav          contoh /sfx/tickle.wav

Format: WAV 16-bit PCM mono atau stereo, 8–48 kHz.

MP3: ESP32-C3 belum decode MP3 di firmware ini. Konversi ke WAV (Audacity).
