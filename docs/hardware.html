⚡ Jalur daya (power path)

🔋 LiPo
   │
   ├── B+ / B− ──→ TP4056 (charger)
   │
   └── OUT+ TP4056 ──→ 🔌 Saklar On/Off ──┬──→ VIN (5V) ESP32-C3
                                         │
                                         └──→ VIN MAX98357  ← dari baterai

ESP32 3V3 ──→ LCD ST7789 (VCC + BLK) + microSD + TTP223
Semua GND digabung

✅ MAX98357 dari setelah saklar (baterai). LCD/SD/touch dari 3V3.

⚠️ Jangan 5V ke VCC LCD.

🛡️ Pin boot-safe (v0.2.3)

ESP32-C3 strapping: GPIO2, GPIO8, GPIO9. Map ini membebaskan GPIO2 & GPIO9 (BOOT).

                 ESP32-C3 Super Mini  — pin map v0.2.3
                 ┌───────────────────┐
           3V3 ─│ 3V3            GND  │─ GND bersama
     TFT MOSI ─│ GPIO6          GPIO4 │─ TFT SCLK + SD SCK
      TFT CS  ─│ GPIO7          GPIO0 │─ TFT RST   ← aman
      TFT DC  ─│ GPIO10         GPIO5 │─ SD CS
      SD MISO ─│ GPIO3          GPIO1 │─ TTP223 OUT  ← aman (bukan GPIO2)
   I2S DIN    ─│ GPIO8          GPIO20│─ I2S LRC
   I2S BCLK   ─│ GPIO21         GPIO2 │─ (kosong — strap, jangan pakai)
                 │               GPIO9 │─ (BOOT — kosong)
                 └───────────────────┘
                         VIN ← saklar ← TP4056 OUT+

🧩 Urutan rakit

  1. 🖨️ Cetak 2 STL.
  2. 📺 LCD ke tatakan.
  3. 🔌 GND bersama → 3V3 → SPI (perhatikan pin baru!) → sentuh → I2S.
  4. ⚡ TP4056 → saklar → VIN ESP32 + VIN MAX98357.
  5. 🔋 Baterai ke B+/B−.
  6. 🔊 Speaker ke OUT amp.
  7. 👆 TTP223 ke dinding dalam.
  8. 💻 Flash firmware v0.2.3+, tes sebelum tutup case.

✅ Muat di case?

Muat: C3 Super Mini + TP4056 mini + MAX98357 + saklar + LiPo pipih ≤800 mAh.

❌ Tidak: PAM8403, WROOM besar, 18650.
