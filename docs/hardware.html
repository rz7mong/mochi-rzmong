Model yang didukung firmware 0.5.1

ESP32-C3 Super Mini + LCD ST7789 1.3" 240×240 modul PCB 23×40 mm (8 pin SPI).

  • Ini model DIY Dasai-style yang muat case jendela 23×40 mm.
  • LCD 1.54" (PCB ~32 mm) tidak muat case ini — jangan pakai tanpa redesign STL.
  • Jangan pakai ESP32-WROOM / DevKit besar.

Skema lama (TFT RST=GPIO8, SD MISO=GPIO2, I2S DIN=GPIO9) salah untuk firmware ini. Ikuti tabel di bawah.

⚡ Power

Beban tetap terpasang saat charging membuat terminasi TP4056 kurang akurat. Ideal: saklar memutus beban saat charge.

LiPo → TP4056 (+DW01) → Saklar → VIN ESP32 + VIN MAX98357
ESP32 3V3 → LCD + SD + TTP223
GND bersama
LCD BLK → 3V3 (bukan 5V)

🔊 Speaker

Jangan sambung speaker ke GPIO langsung — hanya lewat MAX98357 OUT+/OUT−.

🧩 Urutan rakit

  1. Cetak case jendela 23×40 mm + tatakan LCD.
  2. Rekatkan LCD 1.3" ke tatakan, kabel ke belakang. BLK ke 3V3.
  3. Solder urutan: GND bersama → 3V3 → SPI layar → SPI SD → sentuh GPIO1 → I2S 21/20/8.
  4. Speaker ke OUT amp. Jangan pakai GPIO2 atau GPIO9.
  5. TP4056 berproteksi → saklar → VIN.
  6. Flash firmware 0.5.1 dari halaman instalasi (Erase NVS aman; SD tidak terhapus).
  7. Wi-Fi rzmong mochi / rzmong123 → http://192.168.4.1/.
