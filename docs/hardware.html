📦 Case & cetak 3D

Pakai file case yang sudah ada di proyek:

  • Kulit luar — case_luar_lcd_23_40mm.stl
  • Dudukan LCD — tatakan_lcd_23_40mm.stl

Cetak PLA, layer 0.2 mm, infill 15–20%. Jendela depan 23×40 mm.

🧩 Urutan rakit

  1. 🖨️ Cetak 2 STL. Rapikan jendela LCD.
  2. 📺 Rekatkan LCD ke tatakan, kabel ke belakang.
  3. 🦳 Solder urutan: GND bersama → 3V3 → SPI layar → SPI SD → sentuh → I2S → TP4056 ke VIN.
  4. 🔋 Baterai ke B+/B− TP4056. Jangan balik polaritas.
  5. 🔊 Speaker ke OUT ampli, tidak ke pin ESP.
  6. 👆 Pad sentuh TTP223 menempel ke dinding dalam kepala.
  7. 🔌 Instal firmware, tes LCD sebelum case ditutup.
  8. 💾 Masukkan microSD FAT32 berisi /gif dan /sfx.
  9. 🔒 Tutup case luar, jangan jepit kabel backlight.

⚠️ Muat di case?

Muat jika pakai C3 Super Mini + TP4056 mini + MAX98357 + baterai pipih ≤800 mAh + speaker tipis. Tidak muat jika PAM8403, ESP32-WROOM besar, atau baterai 18650.
