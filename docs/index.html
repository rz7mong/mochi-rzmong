🔌 Instalasi ESP32 by rzmong

📱
Pakai Chrome atau Edge
Jangan Safari / Instagram in-app. Buka halaman ini di laptop atau HP Android yang mendukung Web Serial.
⚡
Masuk mode flash
Tahan tombol BOOT di ESP32-C3 Super Mini. Sambil tetap ditahan, colok kabel USB-C ke komputer.
🔌
Napa firmware
Lepas BOOT. Tekan tombol instal di bawah. Pilih port COM / USB JTAG. Tunggu sampai selesai, lalu tekan Reset.
📶
Wi-Fi Mochi
Setelah nyala, Mochi membuat jaringan Mochi-rzmong sandi rzmong24. Buka http://192.168.4.1 atau halaman Pengaturan.
💾
Kartu SD
Format FAT32. Salin folder gif/, sfx/, themes.json, dan opsional music/. Colok modul SD, nyalakan ulang.

📖 Ringkas cara pakai

  1. 👆 Ketuk 1× kepala = GIF berikutnya dalam tema yang sama.
  2. 👆👆 Ketuk 2× = menu di LCD (tema, acak, musik, bisu).
  3. ⏳ Tahan 1 detik = bisukan / bunyikan SFX.
  4. 🎨 Ganti tema di menu LCD atau halaman Pengaturan.
  5. 🎵 Lagu: taruh MP3 di /music/, pilih Musik di menu.
