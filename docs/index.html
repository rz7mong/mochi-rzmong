Instalasi ESP32 by rzmong

1
Pakai Chrome atau Edge
Jangan Safari / browser dalam aplikasi. Web Serial harus aktif.
2
Mode flash
Tahan BOOT di ESP32-C3 Super Mini, colok USB-C, lalu lepas BOOT.
3
Instal
Tombol di bawah → pilih port → tunggu selesai → Reset. Setelah nyala, GIF flash langsung jalan (SD tidak wajib).
4
Wi-Fi
Jaringan Mochi-rzmong sandi rzmong24. Pengaturan: halaman Pengaturan atau http://192.168.4.1.
5
SD opsional
FAT32, folder /gif/<tema>/. Tanpa SD tetap ada 10 GIF reaksi di memori chip.

Ringkas cara pakai (model sekarang)

  1. Ketuk 1× kepala = GIF reaksi dari flash (bukan ganti tema).
  2. Ketuk 2× = menu PENGATURAN (16 item).
  3. Tahan 1 detik = bisu / bunyi.
  4. Ganti GIF tema: menu → GIF berikutnya.
