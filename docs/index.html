⚡ Instalasi ESP32 by rzmong

1
🌐 Pakai Chrome atau Edge
Jangan Safari / browser dalam aplikasi.
2
🔘 Mode flash
Tahan BOOT, colok USB-C, lepas BOOT.
3
📥 Instal
Tombol di bawah → pilih port → Reset. GIF flash langsung jalan (SD opsional).
4
📶 Wi-Fi
Mochi-rzmong / rzmong24 → buka Pengaturan untuk pilih tema default.
5
💾 SD opsional
Download mochi-themes.zip → extract ke root SD: /gif/ + /sfx/ + themes.json. Hanya GIF + WAV 16-bit.

🎨 Tema: web = default, ESP32 = manual

  1. Web — sambung Wi-Fi Mochi → Pengaturan → pilih tema (wajah, gundam, mobil, polisi, …) → Simpan. Jadi default boot.
  2. ESP32 + SD — ketuk 2× → menu Pilih tema untuk ganti manual kapan saja.
  3. Tanpa SD — pakai GIF flash bawaan; tema SD tidak aktif.

✨ Ringkas cara pakai

  1. 👆 Ketuk 1× = GIF reaksi + SFX (WAV SD atau jingle flash).
  2. 👆👆 Ketuk 2× = menu PENGATURAN (Pilih tema, Sumber SD/Flash, …).
  3. ✊ Tahan ≥ 900 ms = bisu / bunyi.
  4. 🎞️ Ganti GIF dalam tema: menu → GIF berikutnya.
