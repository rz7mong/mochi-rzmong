⚡ Instalasi ESP32 — firmware 0.5.6

1
Chrome atau Edge (bukan Safari / in-app).
2
Tahan BOOT, colok USB-C, lepas BOOT.
3
Tombol di bawah → pilih port → Install. Centang Erase jika naik dari < 0.5.3.
4
Wi-Fi rzmong mochi / rzmong123 → buka http://192.168.4.1/ untuk pengaturan offline.

Erase menghapus NVS (tema, volume, Chronos). Kartu SD tidak dihapus. Hardware: C3 Super Mini + LCD 1.3" GMT130 27.78×39.22 mm (pin di bawah) — lihat blueprint.

✨ Setelah flash

  1. Pengaturan (disarankan): sambung AP → http://192.168.4.1/ (tanpa internet, tanpa mixed content).
  2. Studio: butuh internet + AP Mochi untuk upload ke SD — studio.html.
  3. Alternatif online: pengaturan.html (dari https ke http AP sering diblokir browser).
  4. LCD: ketuk 2× → menu. Ketuk 1× → reaksi (11 reaksi warna, ada suaranya).
  5. Tanpa SD sudah jalan: 30 GIF+WAV bawaan di flash (wajah default senyum + kedip, wajah/musik warna, mobil, gundam). Pack SD: mochi-themes.zip.
  6. Jam HP: LCD tidak sentuh. Sambung Wi-Fi perangkat, buka http://192.168.4.1/, centang Chronos BLE dan Jam HP, simpan. Lalu sambungkan rzmong di aplikasi Chronos.
