⚡ Instalasi ESP32

1
Chrome atau Edge (bukan Safari / in-app).
2
Tahan BOOT, colok USB-C, lepas BOOT.
3
Tombol di bawah → pilih port → Install.
4
Wi-Fi rzmong mochi / rzmong123 → buka http://192.168.4.1/ di HP (offline, dari perangkat).
5
SD opsional: pack assets-v1 · atau unggah lewat Studio (convert + upload).

⚠️ Centang Erase akan menghapus NVS: tema tersimpan, volume, flag Chronos, dll. kembali ke default.

🎨 Pengaturan

  1. Disarankan: sambung AP → http://192.168.4.1/ (tanpa internet).
  2. Alternatif online: pengaturan.html (butuh akses github.io; di beberapa HP tanpa internet gagal).
  3. LCD: ketuk 2× → menu.
