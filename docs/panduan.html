↕️ Cara jalan / “scrol” menu

Menu tidak bisa digeser. Yang bergerak hanya tanda > tiap kali kepala diketuk.

  1. 👆👆 Ketuk 2× — menu muncul, baris pertama ada >.
  2. 👆 Ketuk 1× — > pindah ke baris bawah. Sampai bawah, ketuk lagi kembali ke atas.
  3. 👆👆 Ketuk 2× — menjalankan baris yang ada >.
  4. Pilih Tutup kalau hanya ingin keluar tanpa ganti apa pun.

Urutan baris: Tema berikutnya → Mode acak → Musik → Bisu → Chronos → Tentang rzmong → Tutup.

🎮 Isi menu LCD

  • 🎭 Tema berikutnya — wajah → gundam → mobil → neon → anime → makanan → musik → intro.
  • 🎲 Mode acak — ketuk 1× bisa loncat lintas tema.
  • 🎵 Musik /music — putar MP3 dari kartu SD.
  • 🔇 Bisu / bunyi — matikan SFX tanpa ganti tema.
  • 🗺️ Chronos — peta & notifikasi HP.
  • 💧 Tentang rzmong — layar boot.
  • ✖ Tutup — kembali ke GIF.

🎭 Ganti tema

Tema seperti tema HP. Gundam hanya GIF Gundam. Mobil hanya mesin, lampu, polisi.

  • 📱 Di Mochi: ketuk 2× → jalankan Tema berikutnya.
  • 🌐 Di web: Wi-Fi Mochi-rzmong / rzmong24 → Pengaturan → pilih chip tema → Simpan.
  • 🎲 Mode: tetap kategori · acak semua · acak dalam tema.

🤪 Pasang / ganti ekspresi GIF

Satu file = satu bagian. Jangan gabung helm+kokpit+tembak.

  • 📁 /gif/wajah/happy.gif + /sfx/wajah/happy.wav
  • 🎨 Unggah lewat Studio, salin ke SD, restart Mochi.
  • 🎬 MP4 ubah ke GIF 240×240 dulu.

🎵 Musik

  • MP3 di /music/.
  • Menu → Musik /music.
  • Ketuk 1× = lagu berikutnya. Tahan = bisu.

🗺️ Chronos

  • App Chronos (Android, fbiego), izinkan notifikasi + peta.
  • Nyalakan Chronos di menu atau Pengaturan web.

💾 Kartu SD

/themes.json
/gif//*.gif

/music/*.mp3

Format FAT32.

❓ Kalau tidak jalan

  • LCD hitam — cek kabel ST7789.
  • Tidak ada wajah — folder /gif// kosong / SD belum kebaca.
  • Tidak ada suara — cek bisu dan nama SFX.
  • Gagal instal — tahan BOOT sebelum colok, pakai Chrome.
