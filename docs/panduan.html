GesturYang terjadi
👆 Ketuk 1×Ganti bagian GIF dalam tema yang sedang aktif. Contoh tema Gundam: kokpit → helm → isyarat → pilot → tembak.
👆👆 Ketuk 2× cepatBuka menu LCD.
⏳ Tahan ±1 detikBisu / bunyi SFX.
Di dalam menu · ketuk 1×Pindah baris menu.
Di dalam menu · ketuk 2×Jalankan baris yang dipilih.

Sensor: TTP223 ke GPIO1. Sentuh permukaan kepala / case, bukan layar.

🎮 Menu di LCD

  • 🎭 Tema berikutnya — wajah → gundam → mobil → neon → anime → makanan → musik → intro → ulang.
  • 🎲 Mode acak — ketuk 1× bisa loncat lintas tema.
  • 🎵 Musik /music — putar MP3 dari kartu SD.
  • 🔇 Bisu / bunyi — matikan SFX tanpa ganti tema.
  • 🗺️ Chronos — nyalakan peta & notifikasi HP.
  • 💧 Tentang rzmong — layar boot bermerek.
  • ✖ Tutup — kembali ke GIF.

🎭 Ganti tema

Tema = folder, seperti tema HP. Pilih Gundam hanya GIF Gundam yang jalan. Pilih Mobil hanya mesin, lampu, polisi.

  • 📱 Di Mochi: ketuk 2× → Tema berikutnya.
  • 🌐 Di web: sambung Wi-Fi Mochi-rzmong / rzmong24 → buka Pengaturan → ketuk chip tema → Simpan.
  • 🎲 Mode putar: Tetap di kategori · Acak semua tema · Acak dalam tema.

🤪 Pasang / ganti ekspresi GIF

Setiap file = satu bagian. Jangan gabung helm+kokpit+tembak jadi 1 GIF.

  • 📁 Struktur SD:
    /gif/wajah/happy.gif
    /sfx/wajah/happy.wav (nama sama)
    /gif/gundam/kokpit.gif
  • 🎨 Buat sendiri: buka Studio → unggah GIF atau MP4 → pilih tema → pasang SFX MP3/WAV → ikuti path yang muncul → salin ke SD.
  • 🎬 MP4 harus diubah ke GIF 240×240 (perintah ffmpeg ada di Studio).
  • 🔄 Cabut-pasang SD atau restart Mochi setelah menambah file.

Tema bawaan: wajah, gundam, mobil, neon, anime, makanan, musik, intro.

🎵 Musik

  • Taruh file .mp3 di folder SD /music/.
  • Menu LCD → Musik /music, atau aktifkan “Izinkan MP3” di Pengaturan.
  • Ketuk 1× = lagu berikutnya. Tahan = bisu.
  • SFX ekspresi tetap di /sfx/<tema>/, terpisah dari lagu.

🗺️ Chronos — peta & notifikasi

  • Pasang aplikasi Chronos (Android, fbiego) di HP.
  • Nyalakan Chronos di menu LCD atau Pengaturan web.
  • Di aplikasi: pilih perangkat ESP32, izinkan notifikasi, aktifkan navigasi peta.
  • Panggilan / chat / belok di maps bisa tampil di Mochi saat mode Chronos hidup.

Format kartu: FAT32. Paket jadi: file mochi-themes.zip di percakapan / rilis repo.

❓ Kalau tidak jalan

  • 📻 LCD hitam — cek kabel ST7789 (MOSI 6, SCLK 4, CS 7, DC 10, RST 8).
  • 🖼️ Tidak ada wajah — SD belum kebaca atau folder /gif/<tema>/ kosong.
  • 🔊 Tidak ada suara — cek bisu, file SFX nama sama dengan GIF, modul MAX98357.
  • 🔌 Gagal napa — tahan BOOT sebelum colok, pakai Chrome, cabut kabel lain.
  • 📶 Tidak muncul Wi-Fi — tekan Reset setelah flash selesai.
