Tema dan media

  • Web offline — sambung AP → http://192.168.4.1/.
  • Studio — studio.html convert GIF+WAV (max ~599 KB), upload ke SD.
  • Pack: Release assets-v1.
  • Di perangkat: GIF 240×240 + WAV 16-bit saja (bukan MP4/MP3).

Studio + Upload

  1. Convert di Studio saat online (FFmpeg.wasm).
  2. Sambung Wi-Fi rzmong mochi.
  3. Upload lewat captive http://192.168.4.1/ atau tombol Upload Studio (sering diblokir mixed-content).
  4. Firmware ≥ 0.5.3, SD FAT32 wajib untuk upload.

GIF terlalu besarStudio target ≤599 KB
