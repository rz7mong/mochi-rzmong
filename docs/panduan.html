Cara jalan menu

  1. Ketuk 2× — menu oranye muncul.
  2. Ketuk 1× — highlight pindah; daftar otomatis gulir (16 item, 7 terlihat).
  3. Ketuk 2× — menjalankan baris.
  4. Pilih Tutup untuk kembali ke GIF tema.

Isi menu LCD

  • GIF berikutnya — satu-satunya cara ganti GIF tema dari sentuh
  • Pilih tema — wajah → gundam → … → intro
  • Ekspresi flash — putar GIF bawaan berikutnya
  • Mode putar — kategori / acak / acak_tema
  • Reaksi acak/tetap
  • Model reaksi — kunci salah satu dari 10
  • Sumber SD/Flash
  • Volume + / Volume − (0–21)
  • Bisu / bunyi
  • Rotasi layar

Tema SD (opsional)

Tanpa SD, Mochi tetap hidup dari flash. SD hanya menambah GIF tema.

FAT32. Tema: wajah, gundam, mobil, neon, anime, makanan, musik, intro.

Wi-Fi & web

  • AP: Mochi-rzmong / rzmong24
  • Pengaturan: thietlap.html
  • Studio unggah GIF SD: studio.html

Chronos

Nyalakan di menu atau Pengaturan web, lalu pakai aplikasi Chronos di HP. Opsional.

Kalau tidak jalan

  • LCD hitam — pin ST7789: SCLK 4, MOSI 6, CS 7, DC 10, RST 8.
  • Sentuh mati — TTP223 OUT ke GPIO1, aktif HIGH.
  • Tidak ada reaksi — flash firmware v0.2.1+ (reaksi ada di chip, bukan SD).
  • SD tidak kebaca — MISO harus GPIO2, CS GPIO5, jangan GPIO5 untuk MISO.
  • Gagal instal — BOOT + Chrome.
