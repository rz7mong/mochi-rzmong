🛠️ Kalau tidak jalan

  • 📺 LCD hitam — SCLK 4, MOSI 6, CS 7, DC 10, RST 0 (bukan 8).
  • 👆 Sentuh mati — TTP223 OUT → GPIO1 HIGH.
  • 💾 SD gagal — MISO GPIO3 (bukan 2), CS GPIO5.
  • 🔊 Suara mati — DIN GPIO8, BCLK 21, LRC 20; VIN amp dari baterai.
  • ⚡ Gagal boot / flash — jangan wiring ke GPIO2 atau GPIO9; BOOT = GPIO9 kosong.
  • 📥 Gagal instal — tahan BOOT + Chrome/Edge.
