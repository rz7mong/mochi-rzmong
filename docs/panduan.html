🎨 Tema

  • Web — Pengaturan → pilih tema → Simpan (default di ESP32).
  • LCD + SD — ketuk 2× → Pilih tema.
  • Pack: Release assets-v1.

🎨 Studio + Upload

  • Sambung Wi-Fi rzmong mochi → buka Studio.
  • Convert MP4→GIF 240×240 dan MP3→WAV di browser, lalu upload ke SD.
  • Butuh kartu SD terpasang. Firmware ≥ 0.4.0.

🎬 / 🔊 Format

  • Animasi: .gif saja (bukan MP4 di perangkat).
  • SFX: WAV 16-bit (bukan MP3).
  • Speaker: hanya lewat MAX98357.
