Tema dan media

  • Web offline — sambung AP → http://192.168.4.1/.
  • Studio — studio.html convert GIF+WAV (max ~599 KB), upload ke SD.
  • Pack: Release assets-v1.

Studio + Upload

  1. Sambung Wi-Fi rzmong mochi.
  2. Buka Studio (butuh internet untuk FFmpeg).
  3. Convert → preview → Save atau Upload. Firmware ≥ 0.4.5, SD wajib untuk upload.
