🎬 / 🔊 Format media

  • Animasi perangkat: .gif saja (bukan MP4).

📶 Wi-Fi

Default: Mochi-rzmong / rzmong24. Sandi lab — ganti jika dipakai di luar lingkungan pribadi. Siapa pun di jaringan AP bisa membuka halaman pengaturan.
