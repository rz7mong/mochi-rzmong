# Theme & media assets

## Official pack location

Only: [GitHub Release `assets-v1`](https://github.com/rz7mong/mochi-rzmong/releases/tag/assets-v1)

Extract to **root of FAT32 microSD**:

```text
/
├── themes.json
├── gif/<tema>/*.gif
└── sfx/<tema>/*.wav
```

## Formats on device

| Type | Format |
| --- | --- |
| Animation | **GIF** 240×240 |
| SFX | **WAV 16-bit PCM** (mono/stereo), not MP3 |
